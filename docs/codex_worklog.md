# 技术工作记录

此文件仅保存可公开的技术结论，不保留私人样本名称、来源、正文、机构、人员、指纹、工作站路径或运行产物位置。

## 编辑核心

采用 JavaScript / Node 24，支持 OOXML 文件编辑与独立 PowerPoint COM 工作进程。原稿保护、目标指纹、批次预检、磁盘检查点、另存、真实读回及资源退出分别验证。CLI/MCP/Skill 尚未实现。

## 原生兼容性

winax 使用兼容的 Node 24 headers 进行项目内构建。专用工作进程开启显式 GC，在关闭任务文稿后跨事件循环回合释放临时 COM 包装对象，避免原生析构或引用残留问题。前台观察器位于父进程，避免 GC 中 COM Release 派发 Windows 消息时重入 JavaScript。

共享 PowerPoint 应用需要独立客户端持有自己的 COM 引用。任务只能按归属关闭自己的文稿；不能仅凭进程名授予强制结束 Office 的权限。实际观察进程退出，不能把发送 Quit 当作完成。

## 编辑实验

保留四种方法：逐文本片段 COM、按文本框 COM、XML 全包压缩、XML 避免媒体重压缩。优化减少跨进程属性调用及媒体重复压缩；是否适合具体文稿须以相同工作量和实际读回验证。

插入文字后重新获取 TextRange。DrawingML 字体子节点必须遵守 schema 顺序。包内容等价与渲染逐像素等价是不同标准；连续导出的状态差异可通过独立 Office 进程复核。具体私人样本数据、计时、截图及日志不公开。
